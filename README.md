# Contact Management System

A beginner Python project for managing contacts through a command-line interface.

## Features
- Add contacts with a name, phone number, and email address.
- Search for contacts by name.
- Display all saved contacts.
- Save contacts to a JSON file.
- Load previously saved contacts when the program starts.
- Validate required fields and handle basic file-reading errors.

## Technologies Used
- Python
- JSON
- Built-in Python modules: `json` and `os`






## What I Learned
This project helped me practise Python functions, lists, dictionaries, loops, conditional statements, string manipulation, file handling, and data persistence using JSON.
